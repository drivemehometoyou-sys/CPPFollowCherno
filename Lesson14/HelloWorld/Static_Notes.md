# C++ static 核心思维笔记（Cherno 21～23）

核心：static 出现的位置不同，作用也不同。

## ① 文件作用域的 static（第 21 节）

关键词：内部链接（Internal Linkage）

```cpp
static int x = 10;
static void Function() {}
```

- 限制名字的链接范围：只能在当前翻译单元内直接引用。
- 避免不同 .cpp 文件中的同名全局变量或函数发生链接冲突。
- 不影响变量是否可以修改。

## ② 类内部的 static（第 22 节）

关键词：属于类，而非对象

```cpp
class Entity
{
public:
    static int x;
    static void Print() {}
};

int Entity::x = 0; // 静态成员变量的定义
```

- 静态成员变量：所有对象共享同一份数据，不属于单个对象。
- 静态成员函数：没有 this 指针，不能直接访问非静态成员。
- 可以通过 Entity::x、Entity::Print() 访问，无须创建对象。
- 普通静态数据成员通常需要在类外提供定义（C++17 的 inline static 是例外）。

## ③ 函数内部的 static（第 23 节）

关键词：局部作用域 + 静态存储期

```cpp
void Function()
{
    static int count = 0;
    count++;
}
```

- 作用域：仅在所在代码块内通过名字访问。
- 存储期：程序运行期间持续存在。
- 只初始化一次，多次调用保留上次的值。
- 典型应用：利用局部静态对象实现单例访问入口。

```cpp
static Singleton& Get()
{
    static Singleton instance;
    return instance;
}
```

第一个 static：静态成员函数，无须对象即可调用。
第二个 static：局部静态对象，只初始化一次。

## 最终记忆框架

| 位置 | 核心作用 | 重点理解 |
| --- | --- | --- |
| 文件作用域 | 控制链接属性 | 其他翻译单元不能通过该名字直接链接引用 |
| 类内部 | 静态成员 | 属于类，不属于具体对象 |
| 函数内部 | 静态存储期 | 作用域局部，状态持久 |

一句话记忆：文件中控制链接，类中实现共享，函数中保留状态。

更深一层：作用域（哪里能使用名字）、链接属性（不同翻译单元中的名字能否指向同一实体）、存储期（对象存在多久）是三个不同概念。
